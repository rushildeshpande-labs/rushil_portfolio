# Rushil Deshpande | Personal Portfolio Website

A simple static personal website, built and deployed as part of the AWS Student Builder Group (VIT Pune) cloud pre-interview tasks.

**Live site:** https://lighthearted-kleicha-1faa6a.netlify.app

## Overview
A one-page portfolio with an intro, the skills I'm learning (Python, DSA, AI/ML, Cloud), my goals, and contact links.

## Technologies Used
- HTML5 and CSS3 (no frameworks, no JavaScript)
- Google Fonts (Bricolage Grotesque, Source Serif 4)
- Git and GitHub for version control
- Netlify for hosting

## Hosting Platform
Netlify. I chose it because it is free, beginner-friendly, and publishes a static site with a public URL in under a minute.

## Deploy It Yourself
1. Clone or download this repository.
2. Go to https://app.netlify.com/drop and log in (a free account is enough).
3. Drag the folder containing `index.html` onto the page.
4. Wait about 30 seconds. Netlify gives you a public URL.
5. (Optional) In Site settings, change the site name to something readable.

## Setup Requirements
- A web browser
- A free Netlify account
- No installs, build steps, or API keys are needed

## Customising
Open `index.html` in a text editor and change the name, text, and contact
